# Presenter Studio MVP Requirements

## MVP Goal

Build a working internal tool that can transform one AlgeriaTech article into a YouTube-ready video package.

## Must Have

- Article text input.
- Script generation.
- Scene plan generation.
- Human edit step.
- Subtitle generation.
- Export script and subtitles.
- Store generated projects.
- Basic YouTube metadata generation.

## Should Have

- URL import.
- 16:9 video render.
- 9:16 short render.
- Presenter/avatar provider integration.
- B-roll/image suggestions.
- Template selection.
- Arabic/French/English output.

## Could Have

- Direct YouTube upload.
- Thumbnail generator.
- Voice cloning.
- Brand kit.
- Team review comments.
- Batch article processing.

## Not In MVP

- Training a custom avatar model.
- Full nonlinear video editor.
- Advanced animation timeline.
- Automatic publishing without review.
- Multi-customer billing.

## First Demo

Input:

- One AlgeriaTech article.

Output:

- 3-minute YouTube script.
- Scene-by-scene storyboard.
- SRT subtitles.
- YouTube title/description/hashtags.
- Optional rough rendered video.
