# Course Generation Workflow

## Goal

Turn source material into a structured training module with lessons, videos, and quizzes.

## Workflow

```text
Document/PPT/PDF
  ↓
Content extraction
  ↓
Learning objective detection
  ↓
Course outline
  ↓
Lesson generation
  ↓
Presenter video scripts
  ↓
Quiz generation
  ↓
Human review
  ↓
Publish/export
```

## Step Details

### 1. Content Extraction

Extract:

- Main sections.
- Definitions.
- Procedures.
- Rules.
- Warnings.
- Examples.

### 2. Learning Objectives

Generate objectives such as:

- Understand the process.
- Identify required documents.
- Follow a safety rule.
- Complete a customer service procedure.

### 3. Course Outline

Structure:

- Course title.
- Module list.
- Lesson list.
- Estimated duration.
- Required quiz score.

### 4. Lesson Generation

Each lesson includes:

- Explanation.
- Presenter script.
- Visual notes.
- Key terms.
- Short summary.

### 5. Quiz Generation

Question types:

- Multiple choice.
- True/false.
- Scenario-based.
- Short answer later.

Each quiz question should include:

- Correct answer.
- Explanation.
- Source section.

### 6. Human Review

Admins should approve:

- Learning objectives.
- Lesson text.
- Quiz answers.
- Required score.
- Published languages.

## Safety Rules

Training content can affect compliance and operations, so generated content should be reviewed before publishing.

For legal, medical, banking, safety, or government training, all final lessons must be approved by a human owner.
