# Learning MVP Requirements

## MVP Goal

Create a simple tool that turns one document into a short training module with lessons and quizzes.

## Must Have

- Document text input.
- Course outline generation.
- Lesson generation.
- Quiz generation.
- Human edit step.
- Export to Markdown or PDF.
- Store generated courses.

## Should Have

- PDF upload.
- Presenter video script per lesson.
- Subtitle generation.
- Arabic/French/English output.
- Basic learner preview.
- Source traceability.

## Could Have

- SCORM export.
- xAPI export.
- LMS integration.
- Learner progress tracking.
- Certificates.
- Team review comments.

## Not In MVP

- Full LMS.
- Enterprise learner management.
- Payment system.
- Advanced grading.
- Proctored exams.

## First Demo

Input:

- A simple company onboarding document or public service FAQ.

Output:

- 3 lesson course.
- 5 question quiz.
- Presenter scripts.
- Summary handout.
