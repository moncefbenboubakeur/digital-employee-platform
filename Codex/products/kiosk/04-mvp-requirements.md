# MVP Requirements

## MVP Goal

Build the Lite First kiosk demo that can answer common questions for one location, use a lightweight talking avatar, and capture unknown questions for admin review.

## Must Have

- Kiosk web app.
- Lightweight 2D/vector/cartoon talking avatar.
- Language selector.
- Microphone input or text input.
- TTS voice output.
- Subtitles.
- Approved answer search.
- Basic semantic matching.
- Unknown question capture.
- Admin page for answer management.
- QR code display.
- Human handoff button.
- Arabic, French, English support.

## Should Have

- Analytics for top questions.
- Confidence scores.
- Suggested questions.
- Idle attract screen.
- Basic customer/location settings.
- Answer status workflow.
- Cost estimate per interaction.

## Could Have

- Live avatar API.
- Automatic video generation in background.
- Premium cached answer video playback.
- Custom voice.
- Darja beta mode.
- Appointment integration.
- Queue ticket integration.
- WhatsApp handoff.

## Not In MVP

- Training custom avatar models from scratch.
- Full live premium realistic avatar.
- Full on-premise deployment.
- Full LMS/SCORM export.
- Complex multi-tenant billing.
- Advanced analytics.
- Government-grade compliance package.

## Demo Content

The first demo should include these approved answers:

- Who are we?
- Where do I go?
- What documents do I need?
- What services are available?
- Can I scan a QR code?
- Can I speak Arabic, French, or English?
