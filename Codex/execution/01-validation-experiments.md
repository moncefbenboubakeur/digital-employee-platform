# Validation Experiments

## Experiment 1: Lite First Demo Kiosk

Question:

Can people understand and enjoy using a low-cost lightweight avatar kiosk?

Build:

- Browser kiosk.
- Lightweight 2D/vector/cartoon avatar.
- TTS voice output.
- Subtitles.
- 20 approved answers.
- Arabic/French/English.
- QR code display.
- Unknown question capture.

Measure:

- Number of questions asked.
- Top repeated questions.
- Completion rate.
- Confusion points.
- Latency.
- Cost per conversation.
- Whether users accept the lightweight avatar as useful.

## Experiment 2: Cached Answer Library

Question:

How many questions can be handled by reusable approved answers before premium video is needed?

Build:

- Semantic matching.
- Confidence thresholds.
- Unknown question capture.
- Answer review queue.

Measure:

- Percent of questions matched to approved answers.
- False matches.
- New question rate.
- Admin review time.
- Which answers deserve premium upgrade.

## Experiment 3: Adaptive Hybrid Upgrade

Question:

Which approved answers should be upgraded from lightweight avatar to premium cached video?

Build:

- Usage ranking for approved answers.
- Admin selection for batch upgrade.
- Premium media placeholder or generated sample.

Measure:

- Top repeated questions.
- Customer willingness to pay for premium answer upgrades.
- Cost difference between live premium and cached premium.
- User perception difference between lightweight and premium answers.

## Experiment 7: Budget Policy

Question:

Do customers understand and value the four avatar policy modes?

Test:

- Lite First.
- Adaptive Hybrid.
- Budgeted Premium.
- Full Live Premium.

Measure:

- Which mode each prospect chooses.
