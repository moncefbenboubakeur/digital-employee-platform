## Working Principles

- Start with the kiosk as the strongest B2B wedge.
- Build bottom-up: Lite First, then Adaptive Hybrid, then Budgeted Premium, then Full Live Premium.
- Use Presenter Studio internally for AlgeriaTech content and as a second product line.
- Treat AI Learning as the enterprise expansion path.
- Use existing avatar, speech, and LLM APIs at first.
- Own the workflow, localization, data, integrations, and customer relationship.
- Cache common answers and reusable media to reduce cost.
- Let customers choose full premium, budgeted premium, adaptive hybrid, or lite-first avatar policies.
- Use human approval for future reuse, not to block live conversations.
- Prioritize Arabic, French, English, and later Darja/Tamazight support.
