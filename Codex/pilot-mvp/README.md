# Pilot MVP Pack

This folder defines the first buildable pilot for the new digital-employee startup.

The recommended first product is:

> Lite First Digital Receptionist for a small public office, branch, mall desk, or company reception.

The goal is not to prove high-end avatar realism. The goal is to prove that a localized AI receptionist can answer common questions, reduce repeated staff interruptions, work in Arabic/French/English, control cost, and improve through cached approved answers.

## MVP Principle

Start with the business truth:

```txt
Visitor needs help
  -> kiosk gives a fast, useful, safe answer
  -> common answers are cached
  -> unknown questions improve the system later
  -> customer controls cost
```

The avatar is important, but it is not the first risk. The first risk is whether the kiosk can reliably answer the right local questions.

## Recommended Pilot Customer

Start with one of these:

- small government/service office
- post office style branch
- mall information desk
- medium company reception

Avoid the first pilot being a giant enterprise. Large customers are valuable later, but the first pilot should be simple enough to deploy, observe, and iterate quickly.
